# oshi-ai-rules

Claude Code の口調を、推しや好きなキャラクターに寄せるための rules テンプレート。

LT「Claude Code の口調を推しにしたら、仕事が楽しくなった話」の配布物です。

## 使い方

1. `rules/oshi.md` をコピーして `~/.claude/rules/` に置く
2. 「　　　　」の空欄を、推しの一人称・語尾・相槌などで埋める
3. Claude Code を起動し直す

書くのは rules ファイル 1 つだけ。あとは Claude Code が勝手に読み込みます。

## 例

- [`examples/imouto.md`](examples/imouto.md) — 元気な妹キャラ
- [`examples/tanukichi.md`](examples/tanukichi.md) — どうぶつの森のたぬきち
- [`examples/kubo.md`](examples/kubo.md) — 真面目で自信なさげなキャラ

## 選ぶ基準

AI に乗せた性格は、そのまま自分にうつります。
「一番好きな推し」ではなく「仕事中に欲しい声」で選ぶのがおすすめです。
